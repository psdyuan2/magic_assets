# 芝麻铺

Magic Assets 的演示页：像素图标、店犬 4 帧循环、CSS FX 装进一个柴犬杂货铺首页。

直接用浏览器打开 `index.html`。

## 资产从哪来

| 产物 | Path | Brief |
| --- | --- | --- |
| `assets/icons/*.svg` | pixel | `briefs/puppy-icons.json` |
| `assets/cycle.css`、`assets/strip.png` | pixel-anim | `briefs/shiba-idle.json` |
| `assets/fx.css`、`assets/fx.js` | fx | `briefs/fx.json` |

`PRODUCT.md` 和 `DESIGN.md` 是当时写给生成流程看的产品/视觉说明。
